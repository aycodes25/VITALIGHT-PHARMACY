# AI Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An admin "AI Import" page where the owner pastes a shop/category URL, the server scans it for products (rule-based, no LLM), the owner reviews each product (edit / approve / reject), and approved products become normal Vitalight products (re-hosted images, visible in admin and on the storefront).

**Architecture:** New admin-only Express router `backend/routes/import.js` drives a stepwise scanner (one page per request, scan state stored in an `import_batches.cursor` column so Vercel time limits are respected and clients cannot tamper with it). Extractors (Shopify feed, WooCommerce Store API, JSON-LD, OpenGraph) live in small modules under `backend/lib/import/`. Scanned items are staged in `import_items`; approving one downloads its images into the `product-images` bucket and inserts a product through the same insert helper the manual "add product" route uses. The React side is a new `ImportPage.jsx` section in the admin.

**Tech Stack:** Node 22+/ESM, Express 5, Supabase (`@supabase/supabase-js`), React 19, Vitest + supertest + Testing Library. No new dependencies.

## Global Constraints

- Extraction is rule-based only (no LLM, no API key). Order: Shopify `/products.json` -> WooCommerce Store API -> JSON-LD `Product` -> OpenGraph/meta. If nothing readable is found, report it; never guess.
- One pasted URL covers: up to 20 listing pages and 200 products (`LIMITS` in `scanner.js`). No whole-site crawl.
- Scanning is stepwise: one HTTP request from the admin page per step.
- Images are downloaded and re-hosted in the Supabase `product-images` bucket at approval time (JPEG/PNG/WebP by magic bytes, max 5 MB each, max 8 per product).
- Categories are chosen by the reviewer per product (pre-filled by a best guess). Source categories are never auto-created.
- Currency is assumed naira; the source currency (when known) is shown in the review screen.
- All outbound fetches go through the SSRF-safe fetcher (public http/https hosts only, re-checked on every redirect, timeout and size caps).
- Every `/api/admin/import/*` route uses the existing `auth.requireAdmin` guard.
- Follow existing style: ESM, no semicolons, single quotes, 2-space indent, plain Vitest tests next to the existing test folders (`backend/test/`, `frontend/src/admin/`).
- Migrations are applied manually in the Supabase SQL editor (see README); the import routes must return a clear message when the new tables are missing.

```js
// routes: { [absoluteUrl]: string (html) | Buffer (png) | object (json) }; anything else answers 404.
export function fakeFetch(routes = {}) {
  const calls = []
  async function fetchImpl(input) {
    const key = String(input)
    calls.push(key)
    const hit = routes[key]
    if (hit === undefined) return new Response('Not found', { status: 404 })
    if (Buffer.isBuffer(hit)) return new Response(hit, { status: 200, headers: { 'content-type': 'image/png' } })
    if (typeof hit === 'string') return new Response(hit, { status: 200, headers: { 'content-type': 'text/html' } })
    return new Response(JSON.stringify(hit), { status: 200, headers: { 'content-type': 'application/json' } })
  }
  return { fetchImpl, calls }
}
```

Create `backend/lib/import/urlSafety.js`:

```js
import net from 'node:net'
import { lookup as dnsLookup } from 'node:dns/promises'

export class ImportError extends Error {
  constructor(message, status = 400) {
    super(message)
    this.name = 'ImportError'
    this.status = status
  }
}

export function isPrivateAddress(address) {
  if (net.isIPv4(address)) {
    const [a, b] = address.split('.').map(Number)
    return a === 0 || a === 10 || a === 127
      || (a === 169 && b === 254)
      || (a === 172 && b >= 16 && b <= 31)
      || (a === 192 && b === 168)
      || (a === 100 && b >= 64 && b <= 127)
      || a >= 224
  }
  if (net.isIPv6(address)) {
    const lower = address.toLowerCase()
    if (lower === '::' || lower === '::1' || lower.startsWith('::ffff:')) return true
    return /^f[cd]/.test(lower) || /^fe[89ab]/.test(lower)
  }
  return true
}

// Validates a user-supplied address and resolves it. The DNS answer is checked here, so a name that points at a
// private network is refused. (A DNS answer that changes between this check and the request is not covered; the
// endpoints that use this are admin-only.)
export async function assertPublicUrl(rawUrl, { lookup = dnsLookup } = {}) {
  let url
  try {
    url = new URL(rawUrl)
  } catch {
    throw new ImportError('Enter a full website address starting with https://')
  }
  if (url.protocol !== 'http:' && url.protocol !== 'https:') {
    throw new ImportError('Only http and https addresses can be scanned.')
  }
  if (url.username || url.password) {
    throw new ImportError('Addresses with a username or password are not allowed.')
  }
  const host = url.hostname.replace(/^\[|\]$/g, '')
  const privateName = host === 'localhost' || host.endsWith('.localhost') || host.endsWith('.local') || host.endsWith('.internal')
  if (privateName) throw new ImportError('That address points to a private network and cannot be scanned.')

  let addresses
  if (net.isIP(host)) {
    addresses = [{ address: host }]
  } else {
    try {
      addresses = await lookup(host, { all: true })
    } catch {
      throw new ImportError('That website address could not be found.')
    }
  }
  if (!addresses.length || addresses.some(({ address }) => isPrivateAddress(address))) {
    throw new ImportError('That address points to a private network and cannot be scanned.')
  }
  return url
}
```

Create `backend/lib/import/safeFetch.js`:

```js
import { assertPublicUrl, ImportError } from './urlSafety.js'

const MAX_REDIRECTS = 3
const DEFAULT_MAX_BYTES = 2 * 1024 * 1024

async function readLimited(response, maxBytes) {
  const chunks = []
  let total = 0
  for await (const chunk of response.body ?? []) {
    total += chunk.length
    if (total > maxBytes) throw new ImportError('The page is too large to scan.', 502)
    chunks.push(chunk)
  }
  return Buffer.concat(chunks)
}

export async function safeFetch(rawUrl, {
  fetchImpl = fetch,
  lookup,
  timeoutMs = 8000,
  maxBytes = DEFAULT_MAX_BYTES,
  accept = '*/*',
} = {}) {
  let current = rawUrl
  for (let hop = 0; hop <= MAX_REDIRECTS; hop += 1) {
    const url = await assertPublicUrl(current, { lookup })
    let response
    try {
      response = await fetchImpl(url, {
        redirect: 'manual',
        signal: AbortSignal.timeout(timeoutMs),
        headers: { 'User-Agent': 'VitalightImporter/1.0 (admin product import)', Accept: accept },
      })
    } catch {
      throw new ImportError('The website did not respond in time.', 502)
    }
    const location = response.headers.get('location')
    if (response.status >= 300 && response.status < 400 && location) {
      current = new URL(location, url).toString()
      continue
    }
    if ([401, 403, 429].includes(response.status)) {
      throw new ImportError('The website refused the request (it may block automated access).', 502)
    }
    if (!response.ok) throw new ImportError(`The website answered with status ${response.status}.`, 502)
    if (Number(response.headers.get('content-length')) > maxBytes) {
      throw new ImportError('The page is too large to scan.', 502)
    }
    const body = await readLimited(response, maxBytes)
    return { url: url.toString(), contentType: response.headers.get('content-type') || '', body }
  }
  throw new ImportError('The website redirected too many times.', 502)
}

export async function fetchText(url, options) {
  const result = await safeFetch(url, options)
  return { url: result.url, text: result.body.toString('utf8'), contentType: result.contentType }
```

```js
// Parses a price written in major currency units ("₦8,500.00", "1.234,50", 8500) into a whole number.
// Returns null when no sensible non-negative number can be read.
export function parsePrice(value) {
  if (value === null || value === undefined || value === '') return null
  if (typeof value === 'number') return Number.isFinite(value) && value >= 0 ? Math.round(value) : null
  const text = String(value).replace(/[^\d.,]/g, '')
  if (!text) return null

  let normalized
  if (!text.includes(',') && /^\d{1,3}(\.\d{3})+$/.test(text)) {
    normalized = text.replace(/\./g, '') // "8.500" is a thousands separator
  } else if (text.lastIndexOf(',') > text.lastIndexOf('.')) {
    normalized = /,\d{1,2}$/.test(text) ? text.replace(/\./g, '').replace(',', '.') : text.replace(/,/g, '')
  } else {
    normalized = text.replace(/,/g, '')
  }
  const number = Number(normalized)
  return Number.isFinite(number) && number >= 0 ? Math.round(number) : null
}
```

```js
import { absoluteUrl, makeItem } from './normalize.js'

const SCRIPT = /<script[^>]*type=["']application\/ld\+json["'][^>]*>([\s\S]*?)<\/script>/gi

function parseBlocks(html) {
  const blocks = []
  for (const match of html.matchAll(SCRIPT)) {
    try {
      blocks.push(JSON.parse(match[1].trim()))
    } catch {
      // Invalid JSON-LD is common; skip the block.
    }
  }
  return blocks
}

function* walk(node) {
  if (Array.isArray(node)) {
    for (const child of node) yield* walk(child)
    return
  }
  if (!node || typeof node !== 'object') return
  yield node
  for (const key of ['@graph', 'itemListElement', 'item', 'mainEntity']) {
    if (node[key]) yield* walk(node[key])
  }
}

const hasType = (node, type) => [].concat(node['@type'] ?? []).includes(type)

function readOffer(node) {
  const offers = [].concat(node.offers ?? [])
    .flatMap((offer) => (offer?.offers ? [].concat(offer.offers) : [offer]))
    .filter((offer) => offer && typeof offer === 'object')
  const offer = offers[0]
  if (!offer) return {}
  const spec = [].concat(offer.priceSpecification ?? [])[0] ?? {}
  return { price: offer.price ?? offer.lowPrice ?? spec.price, currency: offer.priceCurrency ?? spec.priceCurrency }
}

const imageUrls = (image) => [].concat(image ?? []).map((entry) => (typeof entry === 'string' ? entry : entry?.url ?? entry?.contentUrl))
const nameOf = (value) => (typeof value === 'string' ? value : value?.name)

export function extractJsonLdProducts(html, pageUrl) {
  const items = []
  for (const block of parseBlocks(html)) {
    for (const node of walk(block)) {
      const isGroup = hasType(node, 'ProductGroup')
      if (!isGroup && !hasType(node, 'Product')) continue
      const { price, currency } = readOffer(isGroup ? node.hasVariant?.[0] ?? node : node)
      items.push(makeItem({
        name: node.name,
        description: node.description,
        price,
        currency,
        images: imageUrls(node.image),
        sourceUrl: absoluteUrl(node.url, pageUrl) ?? pageUrl,
        category: nameOf([].concat(node.category ?? [])[0]),
        brand: nameOf(node.brand),
      }))
    }
  }
  return items.filter(Boolean)
}

// URLs listed in schema.org ItemList / ListItem entries (product listing pages).
export function extractJsonLdItemUrls(html, pageUrl) {
  const urls = []
  for (const block of parseBlocks(html)) {
    for (const node of walk(block)) {
      if (!hasType(node, 'ListItem')) continue
      const candidate = node.url ?? node.item?.url ?? node.item?.['@id'] ?? (typeof node.item === 'string' ? node.item : null)
      const abs = absoluteUrl(candidate, pageUrl)
      if (abs) urls.push(abs)
    }
  }
  return urls
}
```

```js
function metaContent(html, key) {
  for (const tag of html.match(/<meta\b[^>]*>/gi) ?? []) {
    const name = tag.match(/\b(?:property|name)=["']([^"']+)["']/i)?.[1]
    if (name?.toLowerCase() === key) {
      const content = tag.match(/\bcontent=["']([^"']*)["']/i)?.[1]
      return content === undefined ? null : decodeEntities(content)
    }
  }
  return null
}

// Last-resort extraction from OpenGraph / product meta tags. Needs a price so that ordinary pages are not mistaken for products.
export function extractMetaProduct(html, pageUrl) {
  const price = metaContent(html, 'product:price:amount') ?? metaContent(html, 'og:price:amount')
  if (!price) return null
  const title = metaContent(html, 'og:title') ?? decodeEntities(html.match(/<title[^>]*>([^<]*)<\/title>/i)?.[1] ?? '')
  return makeItem({
    name: title,
    description: metaContent(html, 'og:description'),
    price,
    currency: metaContent(html, 'product:price:currency') ?? metaContent(html, 'og:price:currency'),
    images: [metaContent(html, 'og:image')],
```

```js
    if (url.origin !== page.origin || (!trusted && !PRODUCT_PATH.test(url.pathname))) return
    url.search = ''
    url.hash = ''
    if (url.href !== self.href) urls.add(url.href)
  }

  for (const href of extractJsonLdItemUrls(html, pageUrl)) add(href, { trusted: true })
  for (const tag of html.match(/<a\b[^>]*>/gi) ?? []) {
    const href = hrefOf(tag)
    if (href) add(href)
  }
  return [...urls].slice(0, limit)
}

const pageNumber = (url) => {
  const raw = url.searchParams.get('page') ?? url.pathname.match(/\/page\/(\d+)\/?$/)?.[1]
  const number = Number(raw)
  return Number.isInteger(number) && number > 0 ? number : null
}
const basePath = (url) => url.pathname.replace(/\/page\/\d+\/?$/, '')

export function findNextPageUrl(html, pageUrl) {
  const page = new URL(pageUrl)
  const tags = html.match(/<(?:link|a)\b[^>]*>/gi) ?? []

  for (const tag of tags) {
    if (!/\brel=["'][^"']*\bnext\b[^"']*["']/i.test(tag)) continue
    const abs = absoluteUrl(hrefOf(tag), pageUrl)
    if (abs && new URL(abs).origin === page.origin && abs !== page.href) return abs
  }

  const wanted = (pageNumber(page) ?? 1) + 1
  for (const tag of tags) {
    if (!tag.toLowerCase().startsWith('<a')) continue
    const abs = absoluteUrl(hrefOf(tag), pageUrl)
    if (!abs) continue
    const url = new URL(abs)
    if (url.origin === page.origin && pageNumber(url) === wanted && basePath(url) === basePath(page)) return abs
  }
  return null
}
```

```js
import { fetchJson, fetchText } from './safeFetch.js'
import { ImportError } from './urlSafety.js'
import { SHOPIFY_PAGE_SIZE, parseShopifyProducts, shopifyFeedUrl } from './shopify.js'
import { WOO_PAGE_SIZE, parseWooProducts, wooFeedUrl } from './woocommerce.js'
import { extractJsonLdProducts } from './jsonld.js'
import { extractMetaProduct } from './meta.js'
import { findNextPageUrl, findProductLinks, looksLikeProductUrl } from './links.js'

export const LIMITS = { maxProducts: 200, maxListingPages: 20, productFetchesPerStep: 5 }
export const NO_DATA_MESSAGE = 'This site does not expose product data that can be read automatically. Try a shop or category page, or add the products manually.'

const FEEDS = {
  shopify: { feedUrl: shopifyFeedUrl, parse: parseShopifyProducts, pageSize: SHOPIFY_PAGE_SIZE },
  woocommerce: { feedUrl: wooFeedUrl, parse: parseWooProducts, pageSize: WOO_PAGE_SIZE },
}
const rawCount = (json) => (Array.isArray(json) ? json.length : json?.products?.length ?? 0)

export function productsFromHtml(html, pageUrl) {
  const fromJsonLd = extractJsonLdProducts(html, pageUrl)
  if (fromJsonLd.length) return fromJsonLd
  const fromMeta = extractMetaProduct(html, pageUrl)
  return fromMeta ? [fromMeta] : []
}

// ---- platform feeds (Shopify / WooCommerce) ----

async function readFeed(mode, source, page, opts) {
  const feed = FEEDS[mode]
  const json = await fetchJson(feed.feedUrl(source.href, page), opts).catch(() => null)
  return { items: json ? feed.parse(json, source.origin) : null, count: json ? rawCount(json) : 0, pageSize: feed.pageSize }
}

function feedResult(mode, { items, count, pageSize }, page, total) {
  const kept = items.slice(0, LIMITS.maxProducts - total)
  const newTotal = total + kept.length
  const hasMore = count >= pageSize
  const capped = newTotal >= LIMITS.maxProducts || page >= LIMITS.maxListingPages
  return {
    platform: mode,
    items: kept,
    limitReached: kept.length < items.length || (hasMore && capped),
    cursor: hasMore && !capped ? { mode, page: page + 1, total: newTotal } : null,
  }
}

// ---- generic html pages ----

function htmlResult({ items, queue, listingNext, pages, total }) {
  const kept = items.slice(0, LIMITS.maxProducts - total)
  const newTotal = total + kept.length
  const capped = newTotal >= LIMITS.maxProducts
  const nextUrl = pages >= LIMITS.maxListingPages ? null : listingNext
  const hasWork = queue.length > 0 || Boolean(nextUrl)
  return {
    platform: 'page',
    items: kept,
    limitReached: capped
      ? kept.length < items.length || hasWork
      : Boolean(listingNext) && !nextUrl,
    cursor: capped || !hasWork ? null : { mode: 'html', queue, listingNext: nextUrl, pages, total: newTotal },
  }
}

// A listing page either embeds several products itself or links to product pages that are fetched in later steps.
function absorbListing(page, pagesDone, total) {
  const embedded = productsFromHtml(page.text, page.url)
  const next = findNextPageUrl(page.text, page.url)
  if (embedded.length > 1) return htmlResult({ items: embedded, queue: [], listingNext: next, pages: pagesDone, total })
  return htmlResult({ items: [], queue: findProductLinks(page.text, page.url), listingNext: next, pages: pagesDone, total })
}

async function startHtml(source, opts) {
  const page = await fetchText(source.href, opts)
  const embedded = productsFromHtml(page.text, page.url)
  const links = findProductLinks(page.text, page.url)
  if (embedded.length === 1 && (looksLikeProductUrl(page.url) || links.length === 0)) {
    return htmlResult({ items: embedded, queue: [], listingNext: null, pages: 1, total: 0 })
  }
  if (embedded.length === 0 && links.length === 0) throw new ImportError(NO_DATA_MESSAGE, 422)
  return absorbListing(page, 1, 0)
}

async function htmlStep(cursor, opts) {
  if (cursor.queue.length) {
    const batch = cursor.queue.slice(0, LIMITS.productFetchesPerStep)
    const pages = await Promise.all(batch.map((url) => fetchText(url, opts).catch(() => null)))
    return htmlResult({
      items: pages.flatMap((page) => (page ? productsFromHtml(page.text, page.url).slice(0, 1) : [])),
      queue: cursor.queue.slice(batch.length),
      listingNext: cursor.listingNext,
      pages: cursor.pages,
      total: cursor.total,
    })
  }
  const page = await fetchText(cursor.listingNext, opts)
  return absorbListing(page, cursor.pages + 1, cursor.total)
}

// One step of a scan (one network round of work, sized for a serverless time limit).
// `cursor` is null for the first call; the returned cursor is null when the scan is finished.
export async function scanStep({ url, cursor = null }, opts = {}) {
  const source = new URL(url)
  if (!cursor) {
    for (const mode of Object.keys(FEEDS)) {
      const feed = await readFeed(mode, source, 1, opts)
      if (feed.items?.length) return feedResult(mode, feed, 1, 0)
    }
    return startHtml(source, opts)
  }
  if (cursor.mode === 'html') return htmlStep(cursor, opts)
  if (FEEDS[cursor.mode]) {
    const feed = await readFeed(cursor.mode, source, cursor.page, opts)
    if (!feed.items) throw new ImportError('The website stopped returning products part-way through the scan.', 502)
    return feedResult(cursor.mode, feed, cursor.page, cursor.total)
  }
  throw new ImportError('This scan can no longer be continued. Start a new scan.', 400)
}
```

```js
const words = (text) => String(text ?? '').toLowerCase().split(/[^a-z0-9]+/).filter((word) => word.length > 2)
const stem = (word) => word.replace(/s$/, '')
const normalizeName = (name) => String(name ?? '').toLowerCase().replace(/[^a-z0-9]+/g, ' ').trim()

// Best-guess category for the review screen: the category sharing the most words with the source category/name.
export function suggestCategory(item, categories) {
  const haystack = new Set([...words(item.source_category), ...words(item.name)].map(stem))
  let best = ''
  let bestScore = 0
  for (const category of categories) {
    const score = words(category.name).map(stem).filter((word) => haystack.has(word)).length
    if (score > bestScore) {
      best = category.name
      bestScore = score
    }
  }
  return best
}

export function findDuplicate(item, existingProducts) {
  const key = normalizeName(item.name)
  return key ? existingProducts.find((product) => normalizeName(product.name) === key) ?? null : null
}

export function slugify(name) {
  return String(name ?? '').toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-+|-+$/g, '').slice(0, 50).replace(/-+$/g, '') || 'product'
}

export function uniqueSlug(base, takenIds) {
  if (!takenIds.has(base)) return base
  for (let n = 2; ; n += 1) {
    const candidate = `${base}-${n}`
    if (!takenIds.has(candidate)) return candidate
  }
}
```

```js
import { randomUUID } from 'node:crypto'
import { validateProductInput } from '../validate.js'
import { insertProduct } from '../productStore.js'
import { MAX_IMAGE_BYTES, detectImageType } from '../images.js'
import { safeFetch } from './safeFetch.js'
import { ImportError } from './urlSafety.js'
import { slugify, uniqueSlug } from './match.js'

const MAX_PHOTOS = 8
const BUCKET = 'product-images'

function draftFrom(edits, id) {
  const draft = {
    id,
    name: String(edits.name ?? '').trim(),
    category: edits.category,
    detail: String(edits.detail ?? '').trim().slice(0, 240),
    price: edits.price,
    old_price: edits.old_price ?? null,
    tag: edits.tag ?? '',
    art: edits.art ?? 'vitamin',
    color: edits.color ?? 'lavender',
    stock: edits.stock ?? 0,
    is_active: edits.is_active ?? true,
    featured: edits.featured ?? false,
  }
  if (typeof edits.brand === 'string' && edits.brand.trim()) draft.brand = edits.brand
  return draft
}

async function rehostImage(supabase, productId, url, fetchOpts) {
  const { body } = await safeFetch(url, { ...fetchOpts, maxBytes: MAX_IMAGE_BYTES, accept: 'image/*', timeoutMs: 10000 })
  const type = detectImageType(body)
  if (!type) throw new Error('not a JPEG, PNG or WebP image')
  const path = `${productId}/${randomUUID()}.${type.extension}`
  const { error } = await supabase.storage.from(BUCKET).upload(path, body, { contentType: type.contentType, upsert: false })
  if (error) throw error
  return { path, url: supabase.storage.from(BUCKET).getPublicUrl(path).data.publicUrl }
}

// Saves a reviewed item as a real product: picks a free id, re-hosts the chosen photos, inserts the product.
// Only image URLs found by the scan (item.data.images) can be selected. A photo that fails is skipped with a warning.
export async function approveItem({ supabase, supabaseUrl, item, edits, fetchOpts }) {
  const base = slugify(edits.name)
  const { data: rows, error: lookupError } = await supabase.from('products').select('id').like('id', `${base}%`)
  if (lookupError) throw lookupError
  const id = uniqueSlug(base, new Set((rows ?? []).map((row) => row.id)))

  const draft = draftFrom(edits, id)
  const options = { supabaseUrl, requireId: true, productId: id }
  const early = validateProductInput(draft, options)
  if (early.error) throw new ImportError(early.error, 400)

  const allowed = new Set(item.data?.images ?? [])
  const wanted = [...new Set(Array.isArray(edits.image_urls) ? edits.image_urls : [])]
    .filter((url) => allowed.has(url))
    .slice(0, MAX_PHOTOS)
  const warnings = []
  const results = await Promise.all(wanted.map(async (url) => {
    try {
      return await rehostImage(supabase, id, url, fetchOpts)
    } catch (error) {
      warnings.push(`A photo could not be copied (${url}): ${error.message}`)
      return null
    }
  }))
  const uploaded = results.filter(Boolean)

  const final = validateProductInput({ ...draft, images: uploaded.map((photo) => photo.url) }, options)
  if (final.error) throw new ImportError(final.error, 400)

  const { data, error } = await insertProduct(supabase, final.value)
  if (error) {
    if (uploaded.length) await supabase.storage.from(BUCKET).remove(uploaded.map((photo) => photo.path)).catch(() => {})
    if (error.code === '23505') throw new ImportError('That product ID is already in use. Try approving again.', 409)
    if (error.code === '23503') throw new ImportError('Create the selected category before approving this product.', 400)
    throw error
  }
  return { product: data, warnings }
}
```

```js
import { Router } from 'express'
import { approveItem } from '../lib/import/approve.js'
import { findDuplicate, suggestCategory } from '../lib/import/match.js'
import { scanStep } from '../lib/import/scanner.js'
import { ImportError, assertPublicUrl } from '../lib/import/urlSafety.js'

const UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i
const MIGRATION_MESSAGE = 'The AI import tables are missing. Apply supabase/migrations/005_import_queue.sql in the Supabase SQL editor.'
const ALREADY_HANDLED = 'This product was already approved or rejected, or no longer exists.'

const missingTable = (error) => error?.code === '42P01' || error?.code === 'PGRST205'

function sendError(res, error, fallback) {
  if (error instanceof ImportError) return res.status(error.status).json({ error: error.message })
  if (missingTable(error)) return res.status(503).json({ error: MIGRATION_MESSAGE })
  console.error(`${fallback} ${error?.message ?? error}`)
  return res.status(500).json({ error: fallback })
}

export function importRoutes({ supabase, supabaseUrl, auth, fetchOpts = {} }) {
  const router = Router()
  const guard = auth.requireAdmin

  router.post('/scan', guard, async (req, res) => {
    const { url, batchId } = req.body ?? {}
    let createdBatchId = null
    try {
      let batch
      if (batchId !== undefined) {
        if (typeof batchId !== 'string' || !UUID.test(batchId)) return res.status(400).json({ error: 'Invalid scan.' })
        const { data, error } = await supabase.from('import_batches').select('*').eq('id', batchId).maybeSingle()
        if (error) throw error
        if (!data) return res.status(404).json({ error: 'This scan no longer exists.' })
        if (data.status === 'ready') return res.json({ batchId: data.id, added: 0, done: true, platform: data.platform, limitReached: false })
        batch = data
      } else {
        if (typeof url !== 'string' || !url.trim()) return res.status(400).json({ error: 'Paste the website address you want to scan.' })
        await assertPublicUrl(url.trim(), fetchOpts)
        const { data, error } = await supabase.from('import_batches')
          .insert({ source_url: url.trim().slice(0, 2000), status: 'scanning' })
          .select('*')
          .single()
        if (error) throw error
        batch = data
        createdBatchId = data.id
      }

      const step = await scanStep({ url: batch.source_url, cursor: batch.cursor ?? null }, fetchOpts)
      if (step.items.length) {
        const { error } = await supabase.from('import_items').insert(step.items.map((data) => ({ batch_id: batch.id, data })))
        if (error) throw error
      }
      await supabase.from('import_batches')
        .update({ platform: step.platform, cursor: step.cursor, status: step.cursor ? 'scanning' : 'ready' })
        .eq('id', batch.id)
      return res.json({ batchId: batch.id, added: step.items.length, done: !step.cursor, platform: step.platform, limitReached: step.limitReached })
    } catch (error) {
      if (createdBatchId) await supabase.from('import_batches').delete().eq('id', createdBatchId)
      return sendError(res, error, 'The website could not be scanned.')
    }
  })

  router.get('/batches', guard, async (_req, res) => {
    try {
      const { data, error } = await supabase.from('import_batches')
        .select('id, source_url, platform, status, created_at')
        .order('created_at', { ascending: false })
        .limit(10)
      if (error) throw error
      return res.json({ batches: data })
    } catch (error) {
      return sendError(res, error, 'Recent scans could not be loaded.')
    }
  })

  router.get('/batches/:id', guard, async (req, res) => {
    if (!UUID.test(req.params.id)) return res.status(400).json({ error: 'Invalid scan.' })
    try {
      const [batchResult, itemsResult, categoriesResult, productsResult] = await Promise.all([
        supabase.from('import_batches').select('id, source_url, platform, status, created_at').eq('id', req.params.id).maybeSingle(),
        supabase.from('import_items').select('*').eq('batch_id', req.params.id).order('created_at', { ascending: true }).limit(500),
        supabase.from('categories').select('name'),
        supabase.from('products').select('id, name'),
      ])
      for (const { error } of [batchResult, itemsResult, categoriesResult, productsResult]) if (error) throw error
      if (!batchResult.data) return res.status(404).json({ error: 'This scan no longer exists.' })
      const categories = categoriesResult.data ?? []
      const products = productsResult.data ?? []
      return res.json({
        batch: batchResult.data,
        items: (itemsResult.data ?? []).map((row) => ({
          id: row.id,
          status: row.status,
          product_id: row.product_id,
          data: row.data,
          suggested_category: suggestCategory(row.data, categories),
          duplicate: findDuplicate(row.data, products)?.name ?? null,
        })),
      })
    } catch (error) {
      return sendError(res, error, 'The scanned products could not be loaded.')
    }
  })

  router.post('/items/:id/approve', guard, async (req, res) => {
    const { id } = req.params
    if (!UUID.test(id)) return res.status(400).json({ error: 'Invalid product.' })
    let claimed = false
    try {
      // Claim first so a double click cannot create the product twice.
      const { data: item, error } = await supabase.from('import_items')
        .update({ status: 'approved' })
        .eq('id', id)
        .eq('status', 'pending')
        .select('*')
        .maybeSingle()
      if (error) throw error
      if (!item) return res.status(409).json({ error: ALREADY_HANDLED })
      claimed = true
      const { product, warnings } = await approveItem({ supabase, supabaseUrl, item, edits: req.body ?? {}, fetchOpts })
      claimed = false
      await supabase.from('import_items').update({ product_id: product.id }).eq('id', id)
      return res.status(201).json({ product, warnings })
    } catch (error) {
      if (claimed) await supabase.from('import_items').update({ status: 'pending' }).eq('id', id)
      return sendError(res, error, 'The product could not be saved.')
    }
  })

  router.post('/items/:id/reject', guard, async (req, res) => {
    if (!UUID.test(req.params.id)) return res.status(400).json({ error: 'Invalid product.' })
    try {
      const { data, error } = await supabase.from('import_items')
        .update({ status: 'rejected' })
        .eq('id', req.params.id)
        .eq('status', 'pending')
        .select('id')
        .maybeSingle()
      if (error) throw error
      if (!data) return res.status(409).json({ error: ALREADY_HANDLED })
      return res.json({ rejected: true })
    } catch (error) {
      return sendError(res, error, 'The product could not be rejected.')
    }
  })

  return router
}
```

```js
const MAX_MONEY = 100000000

export function draftFromItem(item) {
  const data = item.data ?? {}
  return {
    name: data.name ?? '',
    detail: String(data.description ?? '').slice(0, 240),
    brand: data.brand ?? '',
    tag: '',
    category: item.suggested_category || '',
    price: data.price ?? '',
    old_price: data.old_price ?? '',
    stock: 0,
    images: Array.isArray(data.images) ? data.images : [],
  }
}

const isBlank = (value) => value === '' || value === null || value === undefined
const isWhole = (value, max) => Number.isInteger(Number(value)) && Number(value) >= 0 && Number(value) <= max

export function itemProblems(draft) {
  const problems = []
  const name = String(draft.name).trim()
  if (name.length < 2 || name.length > 120) problems.push('Enter a product name (2 to 120 characters).')
  if (!draft.category) problems.push('Choose a category.')
  if (isBlank(draft.price) || !isWhole(draft.price, MAX_MONEY)) problems.push('Enter the price as a whole number.')
  if (!isBlank(draft.old_price) && !isWhole(draft.old_price, MAX_MONEY)) problems.push('The original price must be a whole number or empty.')
  if (isBlank(draft.stock) || !isWhole(draft.stock, 1000000)) problems.push('Enter the stock quantity.')
  if (String(draft.detail).trim().length > 240) problems.push('The description can be up to 240 characters.')
  if (String(draft.tag).trim().length > 30) problems.push('The badge can be up to 30 characters.')
  return problems
}

export function payloadFromDraft(draft) {
  return {
    name: String(draft.name).trim(),
    detail: String(draft.detail).trim(),
    brand: String(draft.brand ?? '').trim(),
    tag: String(draft.tag).trim(),
    category: draft.category,
    price: Number(draft.price),
    old_price: isBlank(draft.old_price) ? null : Number(draft.old_price),
    stock: Number(draft.stock),
    image_urls: draft.images,
    is_active: true,
    featured: false,
    art: 'vitamin',
    color: 'lavender',
  }
}

export function summarize(items) {
  const count = (status) => items.filter((item) => item.status === status).length
  return { total: items.length, pending: count('pending'), approved: count('approved'), rejected: count('rejected') }
}
```

```jsx
import { useCallback, useEffect, useState } from 'react'
import { formatPrice } from '../../../shared/money.js'
import { draftFromItem, itemProblems, payloadFromDraft, summarize } from './importHelpers.js'

const MAX_SCAN_STEPS = 60
const base = '/api/admin/import'

function ImportCard({ item, draft, categories, editing, busy, onChange, onToggleEdit, onApprove, onReject }) {
  const problems = itemProblems(draft)
  const pending = item.status === 'pending'
  const set = (key) => (event) => onChange({ ...draft, [key]: event.target.value })
  const name = draft.name || 'product'
  return (
    <article className={`import-card import-${item.status}`}>
      <div className="import-card-media">
        {draft.images.length
          ? draft.images.map((src) => (
            <span className="import-thumb" key={src}>
              <img src={src} alt="" loading="lazy" referrerPolicy="no-referrer" />
              {editing && pending && <button type="button" aria-label={`Remove photo from ${name}`} onClick={() => onChange({ ...draft, images: draft.images.filter((url) => url !== src) })}>×</button>}
            </span>
          ))
          : <span className="import-no-photo">No photo found</span>}
      </div>
      <div className="import-card-body">
        {!pending && <span className={`import-status import-status-${item.status}`}>{item.status === 'approved' ? 'Approved' : 'Rejected'}</span>}
        {item.duplicate && pending && <span className="import-duplicate">Already in your store as “{item.duplicate}”</span>}
        {editing && pending ? (
          <div className="import-edit-grid">
            <label>Name<input aria-label={`Name of ${name}`} value={draft.name} onChange={set('name')} /></label>
            <label>Price (₦)<input aria-label={`Price of ${name}`} inputMode="numeric" value={draft.price} onChange={set('price')} /></label>
            <label>Original price (₦)<input aria-label={`Original price of ${name}`} inputMode="numeric" value={draft.old_price} onChange={set('old_price')} /></label>
            <label>Brand<input aria-label={`Brand of ${name}`} value={draft.brand} onChange={set('brand')} /></label>
            <label>Badge<input aria-label={`Badge of ${name}`} value={draft.tag} onChange={set('tag')} /></label>
            <label className="import-wide">Description<textarea aria-label={`Description of ${name}`} rows={3} value={draft.detail} onChange={set('detail')} /></label>
          </div>
        ) : (
          <>
            <h3>{draft.name}</h3>
            <p className="import-price">{draft.price === '' ? 'No price found' : formatPrice(draft.price)}{draft.old_price !== '' && <s>{formatPrice(draft.old_price)}</s>}{item.data.currency && item.data.currency !== 'NGN' && <em>Site currency: {item.data.currency}</em>}</p>
            <p className="import-detail">{draft.detail || 'No description found'}</p>
          </>
        )}
        <div className="import-row">
          <label>Category
            <select aria-label={`Category for ${name}`} value={draft.category} disabled={!pending} onChange={set('category')}>
              <option value="">Choose a category</option>
              {categories.map((category) => <option key={category.name} value={category.name}>{category.name}</option>)}
            </select>
          </label>
          <label>Stock
            <input aria-label={`Stock for ${name}`} inputMode="numeric" value={draft.stock} disabled={!pending} onChange={set('stock')} />
          </label>
        </div>
        {item.data.source_url && <a className="import-source" href={item.data.source_url} target="_blank" rel="noreferrer">View on source site ↗</a>}
        {pending && problems.length > 0 && <ul className="import-problems">{problems.map((problem) => <li key={problem}>{problem}</li>)}</ul>}
        {pending && (

            <button type="button" className="admin-secondary-button" aria-label={`${editing ? 'Done editing' : 'Edit'} ${name}`} disabled={busy} onClick={onToggleEdit}>{editing ? 'Done' : 'Edit'}</button>
            <button type="button" className="admin-secondary-button" aria-label={`Reject ${name}`} disabled={busy} onClick={onReject}>Reject</button>
          </div>
        )}
      </div>
    </article>
  )
}

export default function ImportPage({ authRequest, categories, onProductsChanged, setError, setMessage }) {
  const [url, setUrl] = useState('')
  const [recent, setRecent] = useState([])
  const [batch, setBatch] = useState(null)
  const [items, setItems] = useState([])
  const [drafts, setDrafts] = useState({})
  const [editingId, setEditingId] = useState(null)
  const [scanning, setScanning] = useState(false)
  const [busy, setBusy] = useState(false)
  const [progress, setProgress] = useState('')

  const loadRecent = useCallback(async () => {
    try {
      setRecent((await authRequest(`${base}/batches`)).batches)
    } catch (loadError) {
      setError(loadError.message)
    }
  }, [authRequest, setError])

  useEffect(() => { loadRecent() }, [loadRecent])

  async function openBatch(id) {
    const result = await authRequest(`${base}/batches/${id}`)
    setBatch(result.batch)
    setItems(result.items)
    setDrafts(Object.fromEntries(result.items.map((item) => [item.id, draftFromItem(item)])))
    setEditingId(null)
  }

  async function scan(event) {
    event.preventDefault()
    setError('')
    setMessage('')
    setScanning(true)
    let batchId = null
    let found = 0
    try {
      for (let step = 0; step < MAX_SCAN_STEPS; step += 1) {
        setProgress(found ? `Scanning… ${found} products found so far` : 'Scanning the website…')
        const result = await authRequest(`${base}/scan`, { method: 'POST', body: JSON.stringify(batchId ? { batchId } : { url: url.trim() }) })
        batchId = result.batchId
        found += result.added
        if (result.limitReached) setMessage('Stopped at the scan limit (200 products). Scan a more specific category page to get the rest.')
        if (result.done) break
      }
      await openBatch(batchId)
      loadRecent()
    } catch (scanError) {
      setError(scanError.message)
    } finally {
      setScanning(false)
      setProgress('')
    }
  }

  const mark = (id, status) => setItems((current) => current.map((item) => (item.id === id ? { ...item, status } : item)))

  async function approve(item) {
    setBusy(true)
    setError('')
    try {
      const result = await authRequest(`${base}/items/${item.id}/approve`, { method: 'POST', body: JSON.stringify(payloadFromDraft(drafts[item.id])) })
      mark(item.id, 'approved')
      setMessage(result.warnings?.length ? `“${drafts[item.id].name}” was saved. ${result.warnings.join(' ')}` : `“${drafts[item.id].name}” was added to your products.`)
      onProductsChanged()
      return true
    } catch (approveError) {
      setError(approveError.message)
      return false
    } finally {
      setBusy(false)
    }
  }

  async function reject(item) {
    setBusy(true)
    setError('')
    try {
      await authRequest(`${base}/items/${item.id}/reject`, { method: 'POST' })
      mark(item.id, 'rejected')
    } catch (rejectError) {
      setError(rejectError.message)
    } finally {
      setBusy(false)
    }
  }

  async function approveAllValid() {
    const targets = items.filter((item) => item.status === 'pending' && itemProblems(drafts[item.id]).length === 0)
    if (!targets.length || !window.confirm(`Approve ${targets.length} product${targets.length === 1 ? '' : 's'} and add them to your store?`)) return
    for (const item of targets) {
      if (!(await approve(item))) break
    }
  }

  async function rejectAllPending() {
    const targets = items.filter((item) => item.status === 'pending')
    if (!targets.length || !window.confirm(`Reject ${targets.length} pending product${targets.length === 1 ? '' : 's'}?`)) return
    for (const item of targets) await reject(item)
  }

  const counts = summarize(items)
  return (
    <div className="import-page">
      <section className="admin-panel">
        <div className="admin-panel-heading"><div><h2>Scan a website</h2><p>Paste a shop or category link. Only import from sites you have permission to use, such as your suppliers.</p></div></div>
        <form className="import-scan-form" onSubmit={scan}>
          <input aria-label="Website address" type="url" required placeholder="https://supplier.example/collections/all" value={url} onChange={(event) => setUrl(event.target.value)} disabled={scanning} />
          <button className="admin-primary-button" type="submit" disabled={scanning || !url.trim()}>{scanning ? 'Scanning…' : 'Scan'}</button>
        </form>
        {progress && <p className="import-progress" role="status">{progress}</p>}
        {recent.length > 0 && (
          <div className="import-recent">
            <span>Recent scans</span>
            {recent.map((entry) => <button type="button" key={entry.id} className={batch?.id === entry.id ? 'selected' : ''} onClick={() => openBatch(entry.id).catch((openError) => setError(openError.message))}>{entry.source_url.replace(/^https?:\/\//, '')}</button>)}
          </div>
        )}
      </section>

      {batch && (
        <section className="admin-panel">
          <div className="admin-panel-heading">
            <div><h2>Review products</h2><p>{batch.source_url}{batch.platform ? ` · read as ${batch.platform}` : ''}</p></div>
            <div className="import-bulk">
              <button type="button" className="admin-primary-button" disabled={busy || counts.pending === 0} onClick={approveAllValid}>Approve all valid</button>
              <button type="button" className="admin-secondary-button" disabled={busy || counts.pending === 0} onClick={rejectAllPending}>Reject all</button>
            </div>
          </div>
          <div className="import-summary">
            <span><strong data-testid="import-total">{counts.total}</strong> Total products found</span>
            <span><strong data-testid="import-pending">{counts.pending}</strong> Pending</span>
            <span><strong data-testid="import-approved">{counts.approved}</strong> Approved</span>
            <span><strong data-testid="import-rejected">{counts.rejected}</strong> Rejected</span>
          </div>
          <div className="import-list">
            {items.map((item) => (
              <ImportCard
                key={item.id}
                item={item}
                draft={drafts[item.id]}
                categories={categories}
                editing={editingId === item.id}
                busy={busy}
                onChange={(next) => setDrafts((current) => ({ ...current, [item.id]: next }))}
                onToggleEdit={() => setEditingId(editingId === item.id ? null : item.id)}
                onApprove={() => approve(item)}
                onReject={() => reject(item)}
              />
            ))}
          </div>
        </section>
      )}
    </div>
  )
}
```
